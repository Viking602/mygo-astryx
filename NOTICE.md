# 项目与来源

本库建立在 [MyGo](https://github.com/egoist/mygo) 的公开 Go API 上，设计体系参考 [Astryx](https://github.com/meta/astryx)。本项目并非二者的官方发行版。运行时不包含 Astryx 的 React、StyleX 或 npm 包。

本库中的通用 SVG 图标由本项目以简单几何路径定义，不包含外部图标或字体资源包。
