## 行为验证

- 基础按钮动作只触发一次，禁用与加载时不执行；选择、单选、开关和键盘导航更新模型。
- 中文 IME 合成与提交、复制、只读输入、动态重排后的输入身份，以及嵌套浮层的 Escape 顺序和焦点恢复正确。
- 长选择列表在弹层内滚动，End 能把末项滚入可见区域并提交；多选遵守数量上限、跳过禁用项、支持搜索和清空，禁用再启用不会自动重开。
- 菜单勾选、单选、子菜单、禁用与系统上下文菜单可用；命令筛选、方向键跳过禁用、Enter 执行、IME 不执行和 Escape 关闭正确。
- Typeahead 分离稳定 ID 与展示文字；自定义面板可以显式应用和关闭。PowerSearch 验证数字、编辑条件并保护只读筛选。
- 文件浏览使用注入结果验证，真实文件拖放、重复、扩展名、大小、数量、移除和忙碌状态经过测试；默认浏览代码连接系统文件选择器。
- 日期范围按含首尾的日历天数校验，覆盖夏令时、允许日期规则、上下限、默认值、预设和清空。
- HoverCard 延迟开启，Escape / 点击关闭后不会在静止指针下重开；Carousel 循环、Lightbox 缩放、切换、旋转、关闭及焦点恢复正确。
- Resizable 键盘调整遵守模型上下限，收起再展开保留尺寸；Stepper 保护线性与禁用步骤，支持两位数序号。
- Timer 支持暂停、继续和重置；InputGroup 转发输入变化，清除按钮恢复输入焦点。
- Chat 验证 IME、Shift+Enter 换行、Enter 发送、空消息拦截、ID 去重、失败保留草稿、重试、Busy/Stop、只读、上下文发送、复制、反馈、展开说明与工具详情。
- 听写验证可用状态与宿主 Start/Stop 回调；未连接系统语音识别或麦克风。

上述行为由本轮无窗口测试验证。上一轮的实际窗口曾通过基础动作、主题、嵌套弹层、多选、菜单、Lightbox 和聊天；本轮原生复验没有完成，不沿用上轮通过结果。

## 本轮对照修复

先复现了长确认按钮越界、长 MegaMenu 无法滚动到末项、MobileNav 子项目不可达、日期规则依赖时分秒和空日期提交无效默认值，再增加修复与回归测试。补齐头像状态、可交互头像溢出、移动导航入口和 MegaMenu 操作条目；验证长 Popover、双轴滚动、分步面板、聊天上下文保留、窗口缩放后的输入身份，以及 Astryx 原始名称搜索与固定源码链接。

覆盖清单逐条登记 215 个导出记录，显式区分平台适配、弃用迁移和部分支持。TabMenu 的单项操作菜单与 TableFooter 的固定对齐页脚仍为部分支持；不再用泛化的父组件说明视为完整实现。

## 原生运行环境复验记录

本轮真实窗口在初次绘制后没有继续刷新，辅助操作和指针点击均无法更新页面。为隔离本库，另建只包含 MyGo Button 和计数文字的最小程序，同样停留在 `count=0`，`idle` 返回 `window 1 still draws after 1.5s`。使用官方 `MYGO_GPU=0` 软件渲染、指定主屏坐标并请求聚焦仍复现。证据指向当前原生会话或上游绘制调度，尚未定位到具体系统原因。

相关结果保存在 `artifacts/native-probe-default.json`、`artifacts/native-probe.json`、`artifacts/native-failure-tree.json` 和 `artifacts/native-failure.png`。原生脚本保留失败状态，不使用指针回退替代原来的断言。桌面绘制恢复后，执行 `make smoke-native`，继续验证扩展后的原生路径。

中性主题的正文、辅助文字、主按钮和主要状态文字组合通过 4.5:1 对比度检查，高对比度和文字缩放有对应测试。这些检查覆盖指定组合，不是全平台无障碍认证。

## 重复执行与证据

```sh
go test ./...
go vet ./...
make snapshots-all
make smoke-native
```

`smoke-native` 只在 e2e 构建中启用 MyGo 的本地 Unix socket 自动化，通过 `-focus` 置前它自己的窗口，最后只关闭本次启动的进程。每个入口都检查原生选择器已经回写组件名、弹层关闭，再读取对应演示；失败会写入失败报告和界面诊断，避免沿用上一次成功结果。普通构建不包含自动化插件。
